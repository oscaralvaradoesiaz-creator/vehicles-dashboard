# Anuncios de venta de coches

Aplicación web hecha con Streamlit para explorar un conjunto de datos de anuncios de venta de coches usados en EE. UU. (`vehicles_us.csv`).

## Funcionalidad

- Histograma interactivo de la distribución del odómetro.
- Gráfico de dispersión de precio vs. odómetro.
- Casillas de verificación para mostrar u ocultar cada gráfico.

## Contenido del repositorio

- `app.py`: código de la aplicación web.
- `vehicles_us.csv`: datos utilizados.
- `notebooks/EDA.ipynb`: análisis exploratorio de datos.
- `requirements.txt`: librerías necesarias (pandas, plotly, streamlit).
